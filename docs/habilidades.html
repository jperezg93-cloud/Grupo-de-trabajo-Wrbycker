Primera habilidad de Wrbycker

DISPONIBLE COMO CÓDIGO ABIERTO

wrbycker-workspace-report

En un entorno que pueda ejecutar Python y acceder al repositorio, guía a un agente para generar un inventario local de archivos permitidos mediante el comando report --json, sin leer su contenido.

No necesita clave de OpenAI para generar ese informe.

Ver la habilidad en GitHub ↗
EJEMPLO EN COMPUTADORA

¿Qué ejecutaría?

Con Python 3.11+ instalado y desde la raíz del repositorio:

python -m wrbycker_agent report --json

Solo se inspeccionan rutas de texto permitidas y sus metadatos. No es un escaneo de seguridad.

Importante: esta habilidad está publicada para desarrolladores; no está instalada automáticamente en ChatGPT, Codex ni en los visitantes de esta web. Para usarla, debes incorporarla a un entorno compatible que tenga acceso autorizado a las herramientas indicadas. La web Control Center no ejecuta este comando Python.

MCP / integración de agentes

Un servidor MCP podría exponer herramientas a clientes autorizados, mientras las habilidades describirían flujos de uso. Requiere implementación, permisos y pruebas adicionales.

# Ecosistema WrBycker — arquitectura de marca

## Propósito

WrBycker es la **marca paraguas**; no es un solo producto. Bajo ella conviven dos identidades independientes:

1. **Wrbycker Agent Lab / Control Center:** software de código abierto y herramientas gratuitas, con su guía, licencia y repositorio. Esta app no requiere enlaces de afiliación ni integra promociones dentro de sus herramientas.
2. **WrBycker | IA y Afiliados:** recomendaciones, personajes y plataformas externas de creación con IA, incluyendo OurDream cuando corresponda. Se presenta desde Linktree, con avisos comerciales y restricciones de edad apropiadas.

**Portal común:** [Ecosistema WrBycker](https://jperezg93-cloud.github.io/Grupo-de-trabajo-Wrbycker/ecosistema.html). Su función es explicar ambos caminos y dirigir a los destinos correctos sin mezclarlos.

## Enlaces y orden recomendados para Linktree

Estos pasos **todavía requieren editar Linktree**: disponer de acceso a GitHub no permite administrar un perfil de Linktree. No modificar ni sustituir enlaces existentes de afiliación.

Colocar una nueva tarjeta en la sección de proyectos, preferentemente cerca de redes y portafolio:

- **Título:** Wrbycker Control Center · Herramientas gratuitas
- **Descripción:** Organiza ideas, crea personajes y prompts, y prueba herramientas locales sin registro.
- **URL:** https://jperezg93-cloud.github.io/Grupo-de-trabajo-Wrbycker/app/
- **Etiqueta (si existe):** Software / Código abierto / Gratis

Conservar OurDream y otras plataformas en una sección **separada** de recomendaciones. Identificar los enlaces comerciales con una divulgación clara del tipo «Enlaces de afiliado: puedo recibir una comisión por compras elegibles». Mostrar 18+ o avisos de contenido sensible según el destino y las opciones de Linktree.

El portal de GitHub contiene **solo un enlace al perfil general** https://linktr.ee/wrbycker; no crea redirecciones de afiliado, no altera parámetros de seguimiento, no almacena credenciales y no añade los destinos comerciales a la app PWA.

## Comunicación pública

- Una identidad visual coherente: nombre WrBycker, estilo tecnológico oscuro, colores violeta/menta en el área de software.
- Voz de Agent Lab: técnica, gratuita, documentada, centrada en funciones demostrables y limitaciones reales.
- Voz de IA y Afiliados: creativa, editorial, transparente sobre el patrocinio/afiliación y adecuada a la edad del público.
- Se invita a descubrir otros proyectos, nunca se presenta una recomendación comercial como requisito para usar Control Center.

## Estado y limitaciones

- **Hecho en GitHub:** portal público del ecosistema y enlaces de navegación desde la web de Agent Lab, guía y habilidades.
- **Pendiente en Linktree:** añadir enlace de retorno a Control Center y revisar categorías/avisos en el perfil desde su editor.
- **No implementado:** inicio de sesión común, sincronización entre proyectos, API de Linktree o integración técnica de OurDream en Control Center. No se necesita nada de esto para la identidad de marca compartida.

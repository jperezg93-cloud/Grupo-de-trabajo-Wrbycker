Nosotros te guiamos.

Wrbycker Control Center es una aplicación web para organizar ideas y tareas, preparar prompts, diseñar personajes y trabajar con archivos de texto. No necesitas una clave de IA ni conocimientos de programación.

Abrir Control Center ↗Ver las herramientas ↓

Comienza en tres pasos

01 / ABRE

Entra en la aplicación

Abre Control Center desde el enlace superior. En Android puedes usar el menú del navegador para instalarla en tu pantalla de inicio.

02 / CREA

Prueba tu primera tarea

En Tareas, añade «Mi primer proyecto» y cambia su estado cuando avances. Se guarda en este dispositivo.

03 / PROTEGE

Exporta tu respaldo

En Configuración, descarga tu respaldo JSON para conservar tareas, ideas, personajes, plantillas y flujos.

CONSEJO / MÓVIL

Úsala sin conexión

Abre primero la aplicación con internet y consulta en Configuración si indica «Acceso sin conexión preparado ✓». Después podrás probar el modo avión.

¿Qué puedes hacer hoy?

ORGANIZACIÓN

Tareas e ideas

Escribe pendientes, clasifica su progreso, conserva ideas y consulta un resumen de tus avances.

CREACIÓN

Prompt Studio

Selecciona una plantilla, rellena variables como nombre o estilo, copia el resultado o descárgalo como archivo de texto. No genera imágenes por sí mismo.

PERSONAJES

Fichas maestras

Define nombre, personalidad, apariencia y escenario de un personaje. Puedes editarlo y exportar la ficha en Markdown.

REGLAS

Workflows manuales

Convierte la última idea en una tarea (o viceversa) con una regla que tú ejecutas y confirmas. No trabaja en segundo plano.

ARCHIVOS

Informe de texto

Selecciona un archivo admitido de hasta 256 KB para ver su tamaño, líneas, palabras y vista previa local.

DATOS

Respaldo y restauración

Descarga un respaldo JSON y restáuralo cuando lo necesites. Importar reemplaza los datos existentes y te pide confirmación.

Privacidad desde el inicio: las funciones descritas trabajan en tu navegador. Tus datos se guardan localmente y no se sincronizan entre dispositivos. Exporta una copia antes de cambiar de teléfono o borrar datos del sitio.

Preguntas frecuentes

¿Necesito pagar una suscripción?

No para las herramientas del Control Center. El agente Python opcional y las API comerciales son proyectos aparte y podrían requerir recursos o créditos.

¿Wrbycker es un chatbot con IA?

No. Esta aplicación ejecuta herramientas locales y flujos manuales, pero no incorpora un modelo generativo. El laboratorio Python del repositorio es un componente distinto.

¿Puedo usarla en otro celular?

Sí, puedes abrir la web desde otro dispositivo, pero tus tareas y personajes no se sincronizan automáticamente. Usa el respaldo JSON para transferirlos.

¿Qué son las habilidades para agentes?

Son instrucciones reutilizables para tareas específicas en entornos de agentes compatibles. Nuestro proyecto tiene una sección de Habilidades, independiente de las funciones que hoy corre la web.

¿Quieres contribuir?

El código del proyecto y sus límites técnicos están documentados en GitHub. Puedes informar errores y proponer mejoras.

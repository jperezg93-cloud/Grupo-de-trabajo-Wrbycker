01 — LA IDEA

Más que una respuesta.
Un espacio para experimentar.

El proyecto demuestra cómo separar lo que propone un modelo de lo que un programa tiene permiso para hacer. Las funciones reales se ejecutan en Python, en tu equipo, con validaciones propias.

Es un MVP educativo. No promete autonomía ilimitada, certificación de seguridad, integración MCP ni AG-UI.

02 — CAPACIDADES

Hecho para aprender.
Diseñado para limitar riesgos.

01⌘

Workspace delimitado

Consulta únicamente archivos de texto permitidos; sin comandos del sistema ni acceso indiscriminado al disco.

02◇

Informe sin API

Cuenta archivos, extensiones y tamaños sin leer su contenido ni consumir créditos de OpenAI.

03✓

Aprobación humana

Las notas nuevas exigen una confirmación interactiva y no pueden sobrescribir archivos existentes.

04≋

Auditoría local

Registros básicos enlazados por SHA-256 para detectar alteraciones sencillas del historial.

04 — TRANSPARENCIA

La seguridad empieza
por conocer los límites.

Las medidas de este proyecto son educativas: no constituyen un sandbox resistente a atacantes. No proceses contraseñas ni información confidencial en los directorios de prueba.

La conexión con OpenAI es opcional y puede enviar el texto de los archivos leídos y generar costos. Este sitio no ejecuta el agente ni solicita claves de API.

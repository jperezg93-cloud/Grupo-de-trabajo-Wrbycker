# Contribuir

Gracias por colaborar con Wrbycker Agent Lab.

1. Abre un issue con el problema y el comportamiento esperado (sin secretos ni datos personales).
2. Crea una rama para los cambios y añade pruebas de regresión.
3. Ejecuta `python -m unittest discover -s tests -v` (Python 3.11+).
4. Presenta un pull request que explique el cambio, riesgos y pruebas ejecutadas.

Se priorizan mejoras de seguridad, experiencia de instalación, pruebas y documentación. No agregues dependencias ni permisos peligrosos sin justificar el impacto. Respeta las licencias y atribuciones de componentes de terceros.

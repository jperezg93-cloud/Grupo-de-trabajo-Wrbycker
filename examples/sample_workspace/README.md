# Carpeta de ejemplo

Este espacio contiene texto ficticio para probar comandos de solo lectura. No hay secretos, datos personales ni claves.

## Tareas

- Revisar la documentación del proyecto.
- Generar un inventario local sin conexión a internet.
- Preparar notas que requieran aprobación humana antes de crearse.

Ejemplos desde la raíz del repositorio:

```bash
python -m wrbycker_agent --workspace examples/sample_workspace report
python -m wrbycker_agent --workspace examples/sample_workspace files
python -m wrbycker_agent --workspace examples/sample_workspace read README.md
```
